# docs

Owner: **Jayden** (only Jayden edits files in this folder), with one exception: `BUILD_GUIDE.md` is added by **Bessel** in Phase 1.

This folder holds everything that is not code: guides, design, testing, the user manual, diagrams and branding.

What goes here:

- `BUILD_GUIDE.md` - the build order and supervisor guide for the whole team.
- `deliverables/` - the Deliverable 1 and 2 files, unchanged.
- `brand/` - the company logo and branding notes.
- `design/` - style guide, page inventory and wireframes.
- `diagrams/` - use case diagram, flowchart, class diagram and ER diagram.
- `testing/` - test cases, checklists, reports and test account roles.
- `user-manual/` - the client and admin user manual.
- `demo/` and `presentation/` - demo scripts and the final presentation outline.
- `seed-assets/` - sample property photos used by the seed script.
- `test-plan.md` and `installation-guide.md` - test plan and installation guide.

Rules:

- Never put passwords, tokens or other secrets in this folder. This repository is public.
